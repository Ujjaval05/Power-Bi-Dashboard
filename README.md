# Power-Bi-Dashboard

This repository contains Power BI dashboards developed to analyze and visualize key business metrics across different domains. Each `.pbix` file represents a complete interactive report created using sample datasets.

---

## 📊 Dashboards Included

### 🔹 HR Analytics Dashboard
- **Focus**: Employee attrition, demographics, job roles, and satisfaction levels.
- **Purpose**: Helps HR teams identify trends and make data-driven decisions regarding retention and workforce planning.

### 🔹 Supply Chain Analytics
- **Focus**: Inventory flow, order fulfillment, and supplier performance and product wise analysis.
- **Purpose**: Aims to improve supply chain efficiency and highlight bottlenecks in the logistics process.
